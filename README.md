# داکت اسپلیت مشهد

وب‌سایت استاتیک (HTML/CSS/JS) برای معرفی، فروش، نصب، تعمیر و خدمات داکت اسپلیت در مشهد.

## ساختار پروژه

```
index.html                          صفحه اصلی
style.css / script.js               استایل و اسکریپت مشترک سایت
assets/                              تصاویر و لوگوهای برندها
kharid-daktsplit-mashhad/            خرید داکت اسپلیت در مشهد
gheymat-daktsplit-mashhad/           قیمت داکت اسپلیت در مشهد
nasb-daktsplit-mashhad/              نصب داکت اسپلیت در مشهد
tamir-daktsplit-mashhad/             تعمیر داکت اسپلیت در مشهد
service-daktsplit-mashhad/           سرویس داکت اسپلیت در مشهد
forosh-daktsplit-mashhad/            فروش داکت اسپلیت مشهد
brand-daktsplit/                     برندهای داکت اسپلیت
capacity-daktsplit/                  ظرفیت داکت اسپلیت
calculator-daktsplit/                محاسبه‌گر آنلاین ظرفیت
guide/                                راهنمای تخصصی (هاب) + ۶ مقاله راهنما
sitemap.xml / robots.txt / .htaccess فایل‌های SEO و پرفورمنس
```

## یادداشت‌های فنی

- `SEO-AUDIT.md`, `SEO-MAP.md`, `SEO-FIX-CHANGELOG.md`, `PERFORMANCE-OPTIMIZATION.md`: یادداشت‌های داخلی تیم درباره وضعیت سئو و بهینه‌سازی؛ بخشی از خروجی نهایی سایت نیستند.
- تمام صفحات داخلی (۹ صفحه خدمات/محصول + هاب راهنما) اکنون به‌صورت کامل به یکدیگر لینک داده شده‌اند تا هیچ صفحه‌ای بدون لینک داخلی (orphan) نباشد.
